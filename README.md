Entry for the [make.fun](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) competition **"One Line, One Minute: The Vending Machine Pickup Line Contest"**.

One pickup line spoken by the vending machine itself, in its own world of coils and exact change.

`main.py` (Python 3, stdlib only) writes the entry to `/output/entry.txt`:

> Hey — I don't usually do this, but you pressed all my buttons and now I'm stuck dispensing feelings I don't stock.

The text is 114 characters (UTF-8, within the 1–200 limit), one line, no trailing newline.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
